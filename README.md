# چارتون (Chartoon)

اپ آموزش ترید فارکس و کریپتو به سبک بازی: ۸ دوره‌ی جامع با ۲۷۹ درس (از مبانی و کریپتو تا اسمارت مانی، هارمونیک و الیوت)، درس‌های کوتاه، آزمون پرش و استادی، مرور هوشمند، امتیاز (XP)، روزهای پیاپی با یخ شعله، مأموریت‌های روزانه، دوئل با شمعک یا دوستان، فروشگاه سکه، کارت‌های قابل اشتراک، قلب، لیگ هفتگی و شبیه‌ساز معامله‌ی پیشرفته با پول مجازی (سفارش لیمیت و استاپ، اهرم، اندیکاتور، ابزارهای رسم به سبک تریدینگ‌ویو، ژورنال و آمار، بازپخش بازار، چالش‌ها و قیمت زنده‌ی کریپتو).
با React Native و Expo ساخته شده و فعلاً روی وب اجرا می‌شه (کد برای اندروید و iOS هم آماده‌ست).

> محتوای اپ آموزشیه و توصیه‌ی سرمایه‌گذاری نیست.

**سایت:** https://chartoon.net · **اپ (نسخه‌ی وب، قابل نصب):** https://app.chartoon.net

برنامه‌ی ساخت اپ از نمونه‌ی اولیه تا انتشار: [ROADMAP.md](ROADMAP.md) · وصل کردن سرور: [docs/SUPABASE.md](docs/SUPABASE.md) · لندینگ‌پیج chartoon.net: [docs/SITE.md](docs/SITE.md) · اپ اندروید و گوگل‌پلی: [docs/ANDROID.md](docs/ANDROID.md)

## اجرا

```bash
npm install
npm run web          # اجرای نسخه‌ی وب
npm run build:web    # خروجی استاتیک وب در پوشه‌ی dist، همراه سرویس‌ورکر (sw.js) برای نصب و کار آفلاین
npm run lint
npm run typecheck
npm run validate:content   # بررسی ساختار همه‌ی دوره‌ها و درس‌ها
npx vercel@latest deploy --prod   # انتشار اپ روی Vercel (پروژه‌ی tradingo، تنظیمات در vercel.json؛ سایت: docs/SITE.md)
```

برای حساب ابری، همگام‌سازی و لیگ واقعی، آدرس و کلید Publishable پروژه‌ی Supabase توی `.env.local` قرار می‌گیره (نمونه: `.env.example`) و SQL نصب یه بار روی پروژه اجرا می‌شه. چارتون توی پروژه‌ی مشترک فقط جدول‌ها و توابع `tradingo_*` رو داره و به اپ‌های دیگه دست نمی‌زنه (جزئیات در [docs/SUPABASE.md](docs/SUPABASE.md)). بدون این‌ها اپ کامل و آفلاین کار می‌کنه.

### نسخه‌ی قابل نصب (PWA)

نسخه‌ی وب مثل یه اپ نصب می‌شه (آیکون شمعک روی صفحه‌ی اصلی، پنجره‌ی جدا بدون نوار مرورگر) و بعد از اولین باز شدن بدون اینترنت هم کار می‌کنه:

- **نصب:** توی کروم، اج و سامسونگ اینترنت پنجره‌ی نصب خود مرورگر باز می‌شه؛ توی سافاری آیفون (که پنجره‌ی نصب نداره) قدم‌به‌قدم نشون می‌ده چطور با دکمه‌ی اشتراک به صفحه‌ی اصلی اضافه‌ش کنن. دکمه‌ی نصب توی پروفایله و بعد از دو درس یه نوار کوچیک زیر هدر صفحه‌ی یادگیری هم پیشنهادش می‌ده (با بستنش تا دو هفته نمیاد).
- **آفلاین:** `scripts/build-sw.ts` بعد از هر `expo export` فهرست فایل‌های لازم (بسته‌ی اپ، فونت‌هایی که واقعاً استفاده می‌شن، صداها و آیکون‌ها، حدود ۷ مگابایت) رو توی `dist/sw.js` می‌نویسه. درس‌ها، مرور و شبیه‌ساز آفلاین کار می‌کنن؛ درخواست‌های Supabase و بایننس هیچ‌وقت کش نمی‌شن تا حساب، گفتگو و قیمت‌ها همیشه زنده باشن.
- **به‌روزرسانی:** صفحه همیشه اول از شبکه گرفته می‌شه (اگه شبکه قطع باشه یا بیشتر از ۴ ثانیه طول بکشه، نسخه‌ی ذخیره‌شده باز می‌شه). نسخه‌ی تازه پشت صحنه دانلود می‌شه و وسط درس عوض نمی‌شه؛ یه نوار «نسخه‌ی تازه‌ی چارتون آماده‌ست» میاد و با زدن «به‌روزرسانی» جایگزین می‌شه.

## ساختار

```
src/
  app/                 صفحه‌ها (Expo Router)
    welcome.tsx                 صفحه‌ی شروع
    onboarding.tsx              معرفی مرحله‌به‌مرحله و ثبت‌نام
    signup.tsx, login.tsx       ثبت‌نام و ورود با موبایل (بدون کد تأیید)
    (tabs)/                     یادگیری، تمرین، شبیه‌ساز، گفتگو، پروفایل (لیگ از پروفایل باز می‌شه: league.tsx)
    courses.tsx                 کاتالوگ همه‌ی دوره‌ها (جست‌وجو و دسته‌بندی)
    course/[id].tsx             صفحه‌ی هر دوره و افزودن آن
    account.tsx                 حساب کاربری، همگام‌سازی و خروج
    about.tsx                   درباره و سلب مسئولیت
    lesson/[id].tsx             اجرای درس و تمرین
    guide/[unitId].tsx          راهنمای نوشتاری هر واحد
  components/          کامپوننت‌ها (دکمه‌ی سه‌بعدی، نمودار شمعی، شمعک، ...)
    lesson/            انواع سؤال و کارت آموزش
    sim/               بخش‌های شبیه‌ساز (سفارش، نمودار، بازپخش، آمار، چالش‌ها)
      drawing/         ابزارهای رسم روی نمودار (فهرست ابزارها، لایه‌ی رسم، ویرایش با لمس)
  content/             محتوای آموزشی
    courses/<id>/      هر موضوع یک پوشه: index.ts و u1.ts، u2.ts، u3.ts (واحدها)؛ courses/index.ts موضوع‌ها رو توی ۸ دوره‌ی جامع کنار هم می‌ذاره
    courses/index.ts   فهرست همه‌ی دوره‌ها
    charts.ts          ابزار ساخت نمودار (series، level، الگوها)
    indicators.ts      میانگین متحرک، بولینگر و RSI
    validate.ts        اعتبارسنج محتوا
    types.ts           انواع مرحله‌های درس
  lib/                 منطق خالص و تست‌پذیر: لیگ، معامله و مارجین، آمار، چالش‌ها، بازپخش، رسم روی نمودار، جلسه‌ی درس/تمرین،
                       مرور فاصله‌دار، قلب و Streak، صدا، Supabase و همگام‌سازی
  store/game.ts        وضعیت کاربر (zustand + AsyncStorage)
  theme/               رنگ‌ها و فونت‌ها
public/                manifest، آیکون‌ها (معمولی و maskable) و اسکرین‌شات‌های نصب نسخه‌ی وب (PWA)
supabase/migrations/   جدول‌ها و دسترسی‌های پایگاه‌داده
tests/                 تست‌های واحد (npm test)
scripts/               اعتبارسنجی محتوا و ساخت سرویس‌ورکر (build-sw.ts و sw.template.js)
```

## انواع مرحله‌ی درس

| نوع | توضیح |
|---|---|
| `learn` | کارت آموزش نوشتاری با مثال، نمودار یا نکته |
| `choice` | سؤال چندگزینه‌ای متنی (با داده‌های کمکی اختیاری) |
| `truefalse` | درست یا غلط |
| `fill` | کامل کردن جمله با بانک کلمه |
| `match` | جفت کردن اصطلاح و معنی |
| `chart` | تشخیص الگو یا روند روی نمودار شمعی |
| `predict` | تصمیم خرید یا فروش روی نمودار |
| `tap` | زدن روی کندل درست در نمودار |
| `order` | مرتب کردن مراحل به ترتیب درست |
| `line` | کشیدن یه خط افقی روی نمودار تا قیمت درست (حد ضرر، ورود، هدف، سطح) |

نمودارها می‌تونن سطح افقی، زون (عرضه و تقاضا، اوردربلاک، FVG)، خط روند، برچسب (موج‌ها، سقف و کف‌ها)، میانگین متحرک، بولینگر، حجم و پنل RSI داشته باشن (`ChartSpec` در `types.ts`).

برای اضافه کردن درس، مرحله‌ها رو به فایل واحد مربوط در `src/content/courses/<id>/` اضافه کن و `npm run validate:content` رو اجرا کن. کلمه‌های داخل `**...**` توی متن‌ها برجسته نمایش داده می‌شن. برای دوره‌ی جدید، یه پوشه با `index.ts` بساز و اون رو به `src/content/courses/index.ts` اضافه کن.
