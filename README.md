# تریدینگو (Tradingo)

اپ آموزش ترید فارکس و کریپتو به سبک بازی: بیش از ۳۰ دوره (از مبانی تا اسمارت مانی، هارمونیک و الیوت)، درس‌های کوتاه، آزمون پرش و استادی، مرور هوشمند، امتیاز (XP)، روزهای پیاپی، قلب، لیگ هفتگی و شبیه‌ساز معامله‌ی پیشرفته با پول مجازی (سفارش لیمیت و استاپ، اهرم، اندیکاتور، ژورنال و آمار، بازپخش بازار، چالش‌ها و قیمت زنده‌ی کریپتو).
با React Native و Expo ساخته شده و فعلاً روی وب اجرا می‌شه (کد برای اندروید و iOS هم آماده‌ست).

> محتوای اپ آموزشیه و توصیه‌ی سرمایه‌گذاری نیست.

برنامه‌ی ساخت اپ از نمونه‌ی اولیه تا انتشار: [ROADMAP.md](ROADMAP.md) · وصل کردن سرور: [docs/SUPABASE.md](docs/SUPABASE.md)

## اجرا

```bash
npm install
npm run web          # اجرای نسخه‌ی وب
npm run build:web    # خروجی استاتیک وب در پوشه‌ی dist
npm run lint
npm run typecheck
npm run validate:content   # بررسی ساختار همه‌ی دوره‌ها و درس‌ها
```

برای ورود کاربر، ذخیره‌ی ابری و لیگ واقعی، فایل `.env.example` رو به `.env.local` کپی کن و آدرس و کلید Publishable پروژه‌ی Supabase رو بذار (جزئیات در [docs/SUPABASE.md](docs/SUPABASE.md)). بدون این فایل اپ کامل و آفلاین کار می‌کنه.

## ساختار

```
src/
  app/                 صفحه‌ها (Expo Router)
    welcome.tsx, setup.tsx      خوش‌آمد و انتخاب بازار/سطح
    (tabs)/                     یادگیری، تمرین، شبیه‌ساز، لیگ، پروفایل
    courses.tsx                 کاتالوگ همه‌ی دوره‌ها (جست‌وجو و دسته‌بندی)
    course/[id].tsx             صفحه‌ی هر دوره و افزودن آن
    account.tsx                 ورود، ثبت‌نام و همگام‌سازی
    about.tsx                   درباره و سلب مسئولیت
    lesson/[id].tsx             اجرای درس و تمرین
    guide/[unitId].tsx          راهنمای نوشتاری هر واحد
  components/          کامپوننت‌ها (دکمه‌ی سه‌بعدی، نمودار شمعی، شمعک، ...)
    lesson/            انواع سؤال و کارت آموزش
    sim/               بخش‌های شبیه‌ساز (سفارش، نمودار، بازپخش، آمار، چالش‌ها)
  content/             محتوای آموزشی
    courses/<id>/      هر دوره یک پوشه: index.ts (مشخصات) و u1.ts، u2.ts، u3.ts (واحدها)
    courses/index.ts   فهرست همه‌ی دوره‌ها
    charts.ts          ابزار ساخت نمودار (series، level، الگوها)
    indicators.ts      میانگین متحرک، بولینگر و RSI
    validate.ts        اعتبارسنج محتوا
    types.ts           انواع مرحله‌های درس
  lib/                 منطق خالص و تست‌پذیر: لیگ، معامله و مارجین، آمار، چالش‌ها، بازپخش، جلسه‌ی درس/تمرین،
                       مرور فاصله‌دار، قلب و Streak، صدا، Supabase و همگام‌سازی
  store/game.ts        وضعیت کاربر (zustand + AsyncStorage)
  theme/               رنگ‌ها و فونت‌ها
public/                manifest و آیکون‌های نسخه‌ی وب قابل نصب (PWA)
supabase/migrations/   جدول‌ها و دسترسی‌های پایگاه‌داده
tests/                 تست‌های واحد (npm test)
scripts/               اسکریپت اعتبارسنجی محتوا
```

## انواع مرحله‌ی درس

| نوع | توضیح |
|---|---|
| `learn` | کارت آموزش نوشتاری با مثال، نمودار یا نکته |
| `choice` | سؤال چندگزینه‌ای متنی (با داده‌های کمکی اختیاری) |
| `truefalse` | درست یا غلط |
| `fill` | کامل کردن جمله با بانک کلمه |
| `match` | جفت کردن اصطلاح و معنی |
| `chart` | تشخیص الگو یا روند روی نمودار شمعی |
| `predict` | تصمیم خرید یا فروش روی نمودار |
| `tap` | زدن روی کندل درست در نمودار |
| `order` | مرتب کردن مراحل به ترتیب درست |
| `line` | کشیدن یه خط افقی روی نمودار تا قیمت درست (حد ضرر، ورود، هدف، سطح) |

نمودارها می‌تونن سطح افقی، زون (عرضه و تقاضا، اوردربلاک، FVG)، خط روند، برچسب (موج‌ها، سقف و کف‌ها)، میانگین متحرک، بولینگر، حجم و پنل RSI داشته باشن (`ChartSpec` در `types.ts`).

برای اضافه کردن درس، مرحله‌ها رو به فایل واحد مربوط در `src/content/courses/<id>/` اضافه کن و `npm run validate:content` رو اجرا کن. کلمه‌های داخل `**...**` توی متن‌ها برجسته نمایش داده می‌شن. برای دوره‌ی جدید، یه پوشه با `index.ts` بساز و اون رو به `src/content/courses/index.ts` اضافه کن.
