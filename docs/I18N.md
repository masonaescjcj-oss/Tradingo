# English in Chartoon

Persian is the source language. English is a setting (profile tab, welcome screen); switching
rebuilds every screen, lays the app out left to right and shows Latin digits.

## Interface text: `t()`

Every user-facing Persian string goes through `t()` from `@/i18n`; its English lives in a
dictionary keyed by the exact Persian text.

```tsx
import { t } from '@/i18n';

<Txt>{t('ادامه')}</Txt>
<Button3D label={t('ساخت حساب')} />
t('سلام {name}!', { name })                        // variables in {braces}
t('{n} روز پیاپی', { n: fa(streak), count: streak }) // English entry '{n}-day streak|{n}-day streak'
```

- Dictionaries: `src/i18n/en/app.ts` (src/app), `components.ts` (src/components), `lib.ts`
  (src/lib), `content.ts` (src/content outside lessons). Key = the Persian passed to `t()`,
  value = English with the same `{placeholders}`. `a|b` = singular|plural, picked by `count`.
- Never call `t()` at module top level (the language isn't set yet when modules load). Keep
  constants in Persian and translate where they're shown: `t(ERRORS[kind] ?? 'انجام نشد')`,
  `{items.map((i) => t(i.label))}`.
- Numbers: `fa()` / `faNum()` already give Latin digits in English. Dates:
  `toLocaleDateString(dateLocale(), …)`.
- Layout: English is left to right. Replace hard-coded `textAlign: 'right'` for copy with
  `textStart()`; `writingDirection: 'rtl'` with `textStart() === 'left' ? 'ltr' : 'rtl'`.
  Prices and tickers stay left to right in both.
- Icons: `chevronBack`, `send`, `logout` and `skipEnd` are mirrored in English. Back buttons use
  `chevronBack`; the chevron at the end of a row that opens something is `chevronNext`.
- Data that isn't shown (Persian digits tables, words the chat filter looks for) stays as it
  is with an `// i18n-ignore` comment on the line.
- Check: `npx tsx scripts/i18n-scan.ts <folder>` lists Persian outside `t()`.

## Lessons: overlays

`npx tsx scripts/i18n-source.ts <dir>` writes every unit's Persian strings as
`<dir>/units/<unitId>.json` (path → Persian). The English is a file with the same keys in
`src/content/i18n/en/units/<unitId>.json`; `npx tsx scripts/i18n-index.ts` imports them all
and `npx tsx scripts/i18n-check.ts [--partial | --unit <id>]` checks them.

Rules for lesson English:

- Same keys, nothing added or dropped; items keep their order (answers point at positions).
- Keep every `**highlight**` pair and every `___` blank (same counts as the Persian).
- Fill-in steps: the answers must fit the blanks and the distractors must be plausible.
- Line labels (`…/steps/N/label`) and chart notes at most 12 characters: "Stop loss", "Entry", "Target".
- Latin digits, `%`, `.` for decimals; no Persian characters at all.
- Friendly, short, second person, playful. Standard English trading terms.
