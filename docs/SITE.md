# سایت چارتون (chartoon.net)

لندینگ‌پیج‌های چارتون توی پوشه‌ی `site/` هستن: HTML و CSS ساده، بدون فریم‌ورک و بدون جاوااسکریپت، تا سریع باز بشن و گوگل راحت بخونه‌شون.

| آدرس | فایل | زبان |
| --- | --- | --- |
| `https://chartoon.net/` | `site/index.html` | فارسی (راست‌به‌چپ) |
| `https://chartoon.net/en/` | `site/en/index.html` | انگلیسی |
| هر آدرس اشتباه | `site/404.html` | هر دو |

خود اپ جدا روی **`app.chartoon.net`** می‌مونه (همین پروژه‌ی Expo) و همه‌ی دکمه‌های «شروع رایگان» به اون‌جا می‌رن. کارت‌های اشتراک داخل اپ `chartoon.net` رو نشون می‌دن و لینک دعوت دوئل همیشه آدرس خود اپ رو می‌سازه.

## چی داخلشه

- **رنگ و فونت خود اپ:** همون توکن‌های `src/theme` (پس‌زمینه‌ی سرمه‌ای، سبز صعودی، قرمز نزولی، طلایی) با لاله‌زار برای تیترها، وزیرمتن برای متن و JetBrains Mono برای نمادها. فونت‌ها روی خود سایت هستن (زیرمجموعه‌ی فارسی و لاتین، woff2) و به گوگل‌فونت وابسته نیستن.
- **شمعک:** همون طرح `src/lib/mascotArt.ts`، به‌صورت SVG داخل صفحه. توی هیرو شمعک آخرین کندل یه نمودار صعودیه.
- **اسکرین‌شات‌های واقعی اپ** (`site/assets/shots/*.webp`): مسیر، سؤال درس، نمودار با فیبوناچی، ابزارهای رسم، دوئل، روزهای پیاپی و لیگ.
- **سئو:** عنوان و توضیح با کلیدواژه‌ها (آموزش ترید، فارکس، طلا، کریپتو، تحلیل تکنیکال)، `canonical`، `hreflang` بین فارسی و انگلیسی، Open Graph و کارت توییتر با تصویر اختصاصی هر زبان (`og-fa.png` و `og-en.png`)، داده‌ی ساختاریافته (Organization، WebApplication و FAQPage)، `sitemap.xml` و `robots.txt`.
- خود اپ (`public/index.html`) `noindex` داره تا توی نتایج گوگل، لندینگ‌پیج دیده بشه نه صفحه‌ی خالی اپ.

## انتشار روی Vercel

سایت یه پروژه‌ی دوم توی Vercel از همین مخزنه:

1. توی Vercel: **Add New → Project** و همین مخزن گیت‌هاب رو انتخاب کن.
2. **Root Directory** رو `site` بذار. Framework Preset: **Other**. Build Command خالی بمونه (تنظیمات توی `site/vercel.json` هست).
3. Deploy.
4. توی **Settings → Domains** پروژه‌ی سایت، `chartoon.net` و `www.chartoon.net` رو اضافه کن (www رو روی chartoon.net ریدایرکت کن).
5. توی پروژه‌ی اپ (همون قبلی)، دامنه‌ی `app.chartoon.net` رو اضافه کن.
6. رکوردهای DNS رو همون‌طور که Vercel نشون می‌ده توی پنل ثبت‌کننده‌ی دامنه وارد کن (معمولاً یه رکورد A برای خود دامنه و CNAME برای `www` و `app`).

بعد از بالا اومدن سایت:

- دامنه رو توی **Google Search Console** اضافه کن و `https://chartoon.net/sitemap.xml` رو بفرست. همین کار رو توی **Bing Webmaster Tools** هم بکن.
- لینک صفحه رو توی تلگرام یا واتس‌اپ بفرست تا مطمئن شی پیش‌نمایش (تصویر og) درست میاد.

## وقتی محتوا عوض می‌شه

- عددهای صفحه‌ها (۸ دوره، ۹۳ واحد، ۲۷۹ درس، ۴۲ ابزار رسم و تعداد واحد و درس هر دوره) با تست `tests/site.test.ts` با محتوای واقعی اپ مقایسه می‌شن؛ اگه دوره یا درسی اضافه بشه، تست می‌گه کدوم عدد رو باید عوض کنی.
- CSS دو صفحه عین همه (فقط مسیر فونت‌ها توی نسخه‌ی انگلیسی `../` داره). هر تغییری توی استایل یکی، باید توی اون یکی هم زده بشه.
- اسکرین‌شات‌ها از نسخه‌ی وب اپ با یه کاربر نمونه گرفته شدن (۷۸۰×۱۶۸۸، WebP). اگه ظاهر اپ عوض شد، همون صفحه‌ها رو دوباره بگیر و با همون اسم جایگزین کن.
- `lastmod` توی `sitemap.xml` رو با هر تغییر مهم به‌روز کن.
